# DWARS 2026

Standalone Drupal 11 theme generated against the Drupal 11.3.11 Starterkit
contract and implemented from the UI prototype in the repository root.

Build with `npm install && npm run build`; validate with `npm run check`. Package
version 1.0.2 with `npm run package`; this emits the theme archive and its
SHA-256 checksum in the repository's `artifacts` directory. See
`docs/drupal-theme.md` and `docs/production-release-checklist.md` in the parent
repository for local restore, acceptance, deployment, and rollback instructions.
